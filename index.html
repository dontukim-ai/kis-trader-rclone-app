kis-trader rclone

이 앱은 개인 데이터 수집 서버가 수집한 시장 데이터 파일(시세·뉴스 제목·모의 장부)을 소유자 본인의 Google Drive에 백업하기 위한 개인용 도구입니다. 일반 사용자에게 제공되는 서비스가 아닙니다.

This is a personal tool that backs up market-data files collected by the owner's own server to the owner's own Google Drive. It is not a public service.

사용 권한 / Access

Google Drive API의 drive.file 범위만 사용합니다. 이 앱이 직접 만든 파일과 폴더에만 접근하며, 드라이브의 다른 파일은 읽거나 수정하지 않습니다.

Uses only the drive.file scope: access is limited to files and folders this app creates.
