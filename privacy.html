개인정보처리방침 / Privacy Policy

시행일 / Effective: 2026-11-21

1. 수집하는 정보 / Data accessed

이 앱은 Google Drive API의 drive.file 범위로, 앱이 직접 업로드하거나 만든 파일과 폴더에만 접근합니다. 이름, 이메일, 연락처, 드라이브의 다른 파일 등 개인정보는 수집하지 않습니다.

The app uses only the Google Drive drive.file scope and accesses only files and folders it creates. It does not collect personal information or read any other Drive content.

2. 이용 목적 / Purpose

앱 소유자 본인의 서버에서 수집한 시장 데이터 파일을 소유자 본인의 Google Drive에 백업하는 용도로만 사용합니다.

Used solely to back up the owner's market-data files from the owner's server to the owner's Google Drive.

3. 제공·공유 / Sharing

어떤 데이터도 제3자에게 제공·판매·공유하지 않습니다. Google 사용자 데이터는 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

No data is sold, shared, or transferred to third parties. Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.

4. 보관과 삭제 / Retention and deletion

파일은 소유자의 Google Drive에 보관되며, 소유자가 언제든 삭제할 수 있습니다. 앱 접근 권한은 Google 계정 설정(보안 → 타사 액세스)에서 언제든 철회할 수 있습니다.

Files stay in the owner's Google Drive and can be deleted at any time. Access can be revoked at any time in Google Account settings (Security → Third-party access).
